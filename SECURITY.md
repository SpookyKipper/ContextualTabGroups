# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest 1.x.x | :white_check_mark: |

## Reporting a Vulnerability

There are several ways to report a vulnerability for HKTransports:
1. Via [Spooky Services Advisories Portal](https://advisories.spookysrv.com/request/spooky-services%2Fspookykipper%2Ftab-islands) (Recommended)
2. Via [GitHub Private Vulnerability Reporting](https://github.com/SpookyKipper/ContextualTabGroups/security/advisories/new)
3. Email security@spooky.hk OR security@spookysrv.com with all the details

Please do NOT create GitHub issues for security vulnerabilities.
